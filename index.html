한 사람이 혼자 쓰는 할 일·일정 앱입니다.

모리카는 개발자 본인의 Mac 앱과 개인 서버, 개인 Discord 서버에서만 동작하는 비공개 개인용 도구입니다. 할 일과 프로젝트를 관리하고, 본인이 연결한 Google 캘린더의 일정을 함께 보여 주며, 본인이 요청한 일정을 캘린더에 추가합니다. 일반 사용자에게 배포하거나 판매하지 않습니다.

Google 캘린더 사용

  • 캘린더 목록과 일정 읽기: 앱의 캘린더 화면에 일정을 보여 주기 위해
  • 일정 추가·삭제: 사용자가 직접 요청한 일정만 추가하고, 모리카가 만든 일정만 삭제
  • 참석자 초대, 다른 사람에게 알림 보내기는 하지 않습니다

Morika is a private, single-user task and calendar app. It reads the user's own Google Calendar to show events next to their tasks and adds events only when the user asks. It is not distributed to other users.
