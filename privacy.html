개인정보처리방침

시행일: 2026년 10월 28일

모리카(モリカ, Morika)는 개발자 본인 한 사람만 사용하는 개인용 앱입니다. 이 방침은 모리카가 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

가져오는 정보

  • Google 계정의 이메일 주소: 어떤 계정을 연결했는지 구분하기 위해
  • Google 캘린더 목록과 일정(제목, 시간, 장소, 링크): 앱에서 일정을 보여 주기 위해
  • OAuth 토큰: 사용자가 연결을 끊을 때까지 캘린더에 접근하기 위해

사용 방법

  • 일정은 사용자 본인의 앱 화면과 본인의 개인 Discord 서버에 있는 비서에게만 보여 줍니다.
  • 일정 추가는 사용자가 직접 요청한 경우에만 하며, 참석자를 초대하거나 다른 사람에게 알림을 보내지 않습니다.
  • 모리카가 만든 일정만 삭제합니다.

저장과 공유

  • 토큰과 계정 정보는 사용자 본인의 개인 서버(또는 본인 Mac의 키체인)에만 저장합니다.
  • 일정은 화면에 보여 주기 위해 잠시 메모리에 둘 뿐, 따로 데이터베이스에 쌓지 않습니다.
  • Google 사용자 데이터를 판매하거나 광고에 쓰거나 제3자에게 넘기지 않습니다.
  • 사용자가 비서에게 일정을 물으면, 답을 만들기 위해 해당 일정 내용이 사용자 본인이 계약한 AI 모델 서비스로 전달될 수 있습니다.

Google API 서비스 사용자 데이터 정책

모리카가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

연결 끊기와 삭제

앱의 설정 → 캘린더에서 "연결 끊기"를 누르면 저장된 토큰을 지우고 Google에 접근 권한 취소를 요청합니다. Google 계정 → 서드 파티 액세스에서도 언제든 권한을 취소할 수 있습니다.

문의

이 앱은 개발자 본인만 사용하므로, 문의는 Google OAuth 동의 화면에 표시된 지원 이메일로 하면 됩니다.

English summary: Morika is a private, single-user app. It reads the user's own Google Calendar and adds events only when the user asks. Tokens are stored only on the user's own server or Mac Keychain. Google user data is never sold, used for ads, or shared with third parties. Morika's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked any time from the app or from Google Account → Third-party access.
